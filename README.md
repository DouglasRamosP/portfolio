# Portfolio

Portfólio pessoal estático desenvolvido com HTML e CSS.

## Estrutura

- `index.html`: estrutura principal da página
- `style.css`: estilos base e layout desktop
- `mobile.css`: ajustes responsivos
- `images/`: imagens e previews usados no site

## Como visualizar

Abra o arquivo `index.html` no navegador ou sirva a pasta com um servidor
estático simples.
